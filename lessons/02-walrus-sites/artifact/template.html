Section 1 Validating publish inputs

The four functions you're about to write form a pipeline from loose user inputs to an argv-array the CLI consumes. This first one is the gate.

The site-name regex

const SITE_NAME_PATTERN = /^[A-Za-z0-9._-]{1,64}$/;

Filename-safe characters only, length capped at 64. The constraint isn't from site-builder — it's a hygiene contract for every stage downstream: shell logs, Sui object names, SuiNS labels.
