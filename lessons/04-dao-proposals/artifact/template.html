Section 4 The flash-loan warning + the production fix

⚠ Showcase-only voting surface. Production deployments MUST replace the live balanceOf read with a past-balance snapshot — see below.

The attack — what the live balanceOf read enables

The fix — one substitution

// Showcase (this contract)
uint256 weight = voteToken.balanceOf(msg.sender);

// Production (pair with ERC20Votes; add startBlock to Proposal)
uint256 weight = IVotes(address(voteToken)).getPastVotes(msg.sender, p.startBlock);

The snapshot block is in the past — there's no transaction the attacker can issue now that retroactively gives them tokens at block N. Past-balance reads are unforgeable by any present-time action.
