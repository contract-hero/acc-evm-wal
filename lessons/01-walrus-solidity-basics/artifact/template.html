Why bytes32, not string

bytes32 (this lesson)

mapping(address => bytes32) _anchors;

One slot per anchor → ~22k gas per write. Indexable in events. Constant cost.

string (don't)

mapping(address => string) _anchors;

Stores the ~44-char base64url form. Two+ slots per anchor. Not indexable as a topic.

Section 2 The write path — anchor(bytes32)

Two lines. The EVM does the authentication for free because msg.sender is already cryptographically verified by the time the function runs.

The function

function anchor(bytes32 blobId) external {
    _anchors[msg.sender] = blobId;
    emit Anchored(msg.sender, blobId);
}
