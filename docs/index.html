ACC · Walrus · Solidity

Anchor Walrus blobs from your EVM contracts without leaving Claude Code.

Six lessons that turn the MystenLabs/evm-sui showcases into hands-on builds. ACC clones a reference Foundry or pnpm workspace, walks you section-by-section through the Solidity and TypeScript, and gates every step on the test suite. By the end you've shipped an on-chain blob anchor, an ENS-gated resolver, a DAO whose proposal bodies live on Walrus, and a 10 000-token quilted ERC-721 — five reference apps, 75 passing tests.

Lessons

Each lesson is a runnable reference app — Foundry or pnpm — plus four section prompts that walk you through the load-bearing pieces. Section bodies are mode-agnostic: in learning mode the conductor drops a TODO at the key spot, in explanatory mode it implements + walks through. Every lesson ends green or it doesn't end.

How a lesson runs

ACC handles the setup. You handle the code (or watch — your call). Every section gates on a real test run before advancing, and the same equivalence suite the reference app ships with is what marks the lesson done.

Quick start

Three commands. Foundry-based lessons (01, 03, 04, 06) need forge on PATH; TypeScript lessons (02, 05) need pnpm. ACC's preflight probes catch either and tell you what to install if missing.

1

Install the framework + this course

From any Claude Code session. The course requires agentic-community-college ≥ 0.2.0.

/plugin marketplace add contract-hero/plugin-marketplace
/plugin install agentic-community-college@contract-hero
/plugin install acc-evm-wal@contract-hero
2

Have forge and/or pnpm on PATH

ACC's preflight checks for whichever the lesson needs. forge from Foundry; pnpm from pnpm.io or via corepack enable on Node 22.

3

Start a lesson

ACC renders the lesson catalog, you pick one, and the conductor takes it from there.

/acc-evm-wal:start
Note on workspace location. ACC prompts for a workspace root on first run (default ~/workspace). Each lesson lands in ~/.acc/workspaces/<slug>/; the reference-app seed lives in this repo at lessons/<slug>/reference-app/ and is what ACC copies in. Editing ~/.acc/config.json by hand lets you override per-lesson — a /acc:settings CLI is on ACC's roadmap.
